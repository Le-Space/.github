# Le-Space/.github

Default community health files for the repositories of the **Le-Space** organisation. GitHub uses a file here for every repository of the organisation that has no file of that name itself (see [GitHub Docs: default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)).

## Files

- [`FUNDING.yml`](FUNDING.yml): the **Sponsor** button, pointing to [github.com/sponsors/Le-Space](https://github.com/sponsors/Le-Space). A repository shows it when *Settings → General → Features → Sponsorships* is ticked.
